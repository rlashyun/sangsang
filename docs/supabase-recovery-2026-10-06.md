## 복구 못 한 것 (데이터가 코드에 없음)
1. 연계기관 좌표 `partner_csv` — 0곳. 원본 CSV·키 생성 방식 필요. **연계기관 습득물은 아직 수집하지 않았다**(좌표 없이 수집하면 전부 unmatched).
2. `storage_location_aliases` 별칭 — 0건. 수동 별칭 내역 필요 → 4~5월 미매칭의 직접 원인으로 추정
3. 동명 기관 규칙 중 연계기관 1건(비발디파크) — 위 1번 선행
4. `ingestion_runs` 과거 이력 — 복구 불가. 새 DB의 이력은 id 1~2(중단), 3~10(구간 수집)부터 시작. id 1·2·5는 시간 제한/수동 중단으로 `failed` 처리했다.

## 사용자 결정·작업이 필요한 것
A. **Vercel Production 환경 변수 교체 (미완료)** — `SUPABASE_URL=https://bjbqcntoqpubybrjhrge.supabase.co`, `SUPABASE_SECRET_KEY`는 새 프로젝트 키. 교체 후 재배포. 이 전까지 운영 사이트는 삭제된 옛 DB를 가리킨다. Preview는 운영 DB에 연결하지 않는다(절대 규칙 9). Vercel 접근 권한이 없으면 배포한 팀원에게 요청한다(Hobby 계정은 초대 불가).
B. **크론 `partner-sync` 중지 여부** — 연계기관 좌표가 복구되기 전에는 전부 unmatched로 쌓이므로 꺼 두는 편이 안전하다. 경찰 크론(`police-sync`)은 새 DB 기준으로 정상 동작해야 한다. 배포 후 `CRON_SECRET` 설정도 확인.
C. **남은 ambiguous 199건 처리 범위** — 해당 기관 코드의 전화번호·좌표를 확인해 규칙을 추가할지 결정(10/2 작업과 같은 방식, 판단 필요).
D. **4~5월 미매칭 16,000건** — 김성현의 별칭 자료를 받은 뒤 복구. 센터형 이름을 임의로 기관에 연결하는 것은 PRD 6·절대 규칙 5번상 결정이 필요한 항목.
E. 요금·한도: `bogle-dev` 재개하려면 다른 무료 프로젝트 정지 또는 Pro 월 $25.
F. 재발 방지: 정기 `pg_dump` 백업, 프로젝트 삭제 권한을 owner로 제한.
G. `.env`는 팀원에게 파일째 공유하지 않는다. 키는 비공개 경로로 값만 전달한다. `supabase/.env`에 임시로 넣은 파일이 있으면 삭제한다.

## 복구 작업 파일 (`scripts/recovery/`)
- `sync_police_locations.py` — 커밋 `09cca07`에서 삭제된 옛 `tools/` 복원본. Esri 경찰관서 레이어를 받는다
- `build_police_sql.py` — Esri 데이터를 `storage_locations`(`esri_police`) upsert SQL로 만든다. 실행하면 `police_locations.sql`이 생기며 DB에는 직접 쓰지 않는다
- `sync_by_month.py` — 보존기간을 월 단위 구간으로 나눠 `_sync_source`를 구간별로 호출한다. `--newest-first`로 최신 구간부터 받는다. 최신 등록일(`latest_registered_on`)은 무시한다
- 실행: `uv run python scripts/recovery/sync_by_month.py --source police --start 2026-04-06 --end 2026-10-05 --newest-first`
- 서비스 코드(`src/`)는 이번 복구에서 변경하지 않았다. 이 스크립트들은 복구 재현용이며, 쓰지 않는다면 지워도 서비스에는 영향이 없다
