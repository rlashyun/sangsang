# 2026년 AI 상상그라운드 심사평가표

원본: [ai-sangsang-ground-2026-rubric.pdf](ai-sangsang-ground-2026-rubric.pdf). 아래 표는 검색·인용용으로 원본 내용을 그대로 옮긴 것이다. 내용이 다르면 PDF를 따른다.

## 사업영역 (45점)

| 평가항목 | 세부 평가 지표 | 배점 |
| --- | --- | --- |
| 문제정의 | ○ 특정 산업·직무 또는 일상·사회에서 실제로 발생하는 문제를 구체적이고 타당하게 선정하였는가?<br>- 문제의 구체성과 해결 필요성이 명확하게 제시되었는가?<br>- 실제 사용자 또는 현장의 불편과 필요를 충분히 설명하였는가? | 5점 |
| 해결방안 | ○ 제안한 해결방안이 문제를 효과적으로 해결하고, 공동체 또는 비즈니스 현장에 실질적인 가치를 제공하는가?<br>- 해결방안의 실질적인 효과와 기대효과를 구체적으로 제시하였는가?<br>- 정량적 또는 정성적 근거를 통해 문제 해결 효과를 타당하게 제시하였는가? | 15점 |
| 활동검증 | ○ 프로젝트 수행 과정에서 전문가 및 사용자 검증을 충실히 수행하였는가?<br>- 전문가 및 사용자 의견을 프로젝트에 적절히 반영하였는가?<br>- 검증 과정에서 서비스의 개선이 이루어졌는가?<br>- 검증 대상과 방법이 프로젝트 목적에 적합하였는가? | 15점 |
| 확장가능성 | ○ 제안한 서비스·솔루션은 향후 다른 영역으로 확장되거나 지속 가능한 형태로 발전할 가능성이 있는가?<br>- 타 산업이나 유사 문제 해결 영역으로 적용 범위를 넓힐 수 있는가?<br>- 비즈니스 모델이나 지속 가능한 운영 체계로 발전할 가능성이 있는가? | 10점 |

## 기술·개발 영역 (50점)

| 평가항목 | 세부 평가 지표 | 배점 |
| --- | --- | --- |
| AI 기술 실체 | ○ 구현한 서비스가 단순한 AI 기능 연결을 넘어, 팀의 자체 자산과 결합된 기술 구조를 갖추고 있는가?<br>- 기존 AI 서비스를 단순히 연결한 형태인지, 팀이 보유하거나 구축한 데이터·규칙·기능 등 자체 자산과 결합된 구조인지 확인할 수 있는가? | 15점 |
| MVP 작동성 (발표심사) | ○ 개발한 MVP가 라이브 시연과 심사위원의 지정 입력에서 실제로 작동하는가?<br>- 팀이 준비한 핵심 기능을 라이브로 시연할 수 있는가?<br>- 심사위원이 지정한 새로운 입력에서도 설계한 기능이 작동하는가?<br>- 빈 파일, 긴 입력, 형식이 어긋난 파일 등 경계·극단 입력을 적절하게 처리하는가?<br>- 기능이 실패한 경우 오류 원인을 설명하고, 안내 또는 대체 처리 방식을 제시할 수 있는가? | 10점 |
| 검증·신뢰성 | ○ AI 결과와 서비스 성능을 객관적인 자료와 수치로 검증하였는가?<br>- 정답 데이터와 평가 지표를 활용하여 성능을 검증하였는가?<br>- 실제 사용자 테스트 결과를 수치 또는 기록으로 제시하였는가?<br>- 화면, 수치, 기록, 코드 등 확인 가능한 근거를 제시하였는가?<br>- 검증에 사용한 데이터와 평가 방법이 신뢰할 수 있는 근거를 갖추고 있는가? | 15점 |
| 책임·윤리 | ○ 서비스의 책임·윤리 기준이 설명에만 머물지 않고 실제 구현물에 반영되어 있는가?<br>- 개인정보 또는 민감정보를 다루는 경우 동의 및 마스킹 조치가 구현되어 있는가?<br>- 의료·법률 등 위험한 판단을 요구하는 입력에 대해 적절한 제한이 구현되어 있는가? | 10점 |
